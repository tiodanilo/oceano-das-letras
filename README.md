# Oceano das Letras

Jogo infantil de toque para aprender as letras do alfabeto, com tema de fundo do mar e narração em português.

**Jogar:** https://tiodanilo.github.io/oceano-das-letras/

- **Explorar:** toque numa letra para ver e ouvir a palavra.
- **Ache a letra:** estoure a bolha com a letra pedida.
- **Primeira letra:** descubra com que letra a palavra começa.

A criança escreve o próprio nome no início, tocando nas letras.
